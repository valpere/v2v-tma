# v2v-tma — Voice & Text AI Concierge for Telegram Mini Apps

Інтерактивний **Telegram Mini App (TMA)** голосового та текстового AI-консьєржа для бізнесу з підтримкою мультидоменного каталогу, Voice-to-UI синхронізації та нативної оплати в **Telegram Stars (XTR)**.

---

## 💡 Чому це створено (Вау-ефект та Архітектурний фокус)

Більшість ботів у Telegram — це або звичайні текстові чат-боти, або статичні веб-сторінки у фреймі.
**v2v-tma** поєднує три передові технології в одному рішенні:
1. **Voice-to-UI Synchronization:** Коли користувач каже голосом або пише *«Додай велику піцу Пепероні»*, інтерфейс Mini App оживає на очах — картка підсвічується, позиція додається у кошик, а звукова хвиля анімує відповідь.
2. **Dual Mode (Zero-Cost за замовчуванням):** За замовчуванням консьєрж працює в текстовому режимі з безкоштовним клієнтським синтезом мови (Web Speech API). Жодних перевитрат на хмарні STT/TTS для звичайного перегляду. Режим голосу активується користувачем в один клік (On-Demand).
3. **Telegram Stars Integration:** Офіційний Telegram Payments API для миттєвої оплати цифрових товарів та послуг прямо у шторці WebApp із тактильною віддачею (Haptic Feedback).

## 🏢 4 Готових Бізнес-Домени (Multi-Domain Showcase)

- 🍕 **Піцерія «Папа Пепе»:** неаполітанські страви, підбір пікантності, замовлення з бортиками.
- 💈 **Барбершоп «Барбароса»:** класичні стрижки, моделювання бороди, запис на слоти.
- 🚗 **Автосервіс «Подбай-Авто»:** комп'ютерна діагностика ECU, заміна мастила, гальмівні системи.
- 🛍️ **Магазин «Lyapko Shop»:** голчасті аплікатори та валики лікаря Ляпка для здоров'я спини.

---

## 🛠️ Стек технологій

- **Frontend (TMA):** HTML5, TailwindCSS (dark mode), Vanilla JS ES6+, Telegram WebApp SDK, Web Audio API (хвильовий спектрограф), SpeechRecognition / SpeechSynthesis.
- **Backend:** Go 1.22 (`net/http`), HMAC-SHA256 валідація `initData`, Telegram Payments API (`createInvoiceLink`).
- **Безпека:** Ідемпотентна обробка замовлень, серверна перевірка цін.
